# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use for computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS was launched in 2006 and is used by startups, enterprises, government organizations, educational institutions, and other businesses.

## 2. Global Infrastructure

AWS has a large global infrastructure made up of Regions and Availability Zones. Regions are separate geographic areas, while Availability Zones are isolated locations within a Region designed to improve application availability and resilience. This global infrastructure allows organizations to deploy applications closer to their users and improve performance, availability, and reliability.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and configure cloud resources, monitor services, manage users and permissions, check billing and usage information, and work with resources in different AWS Regions.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual computing resources in the AWS Cloud. It allows users to create and run virtual servers for websites, applications, development environments, databases, and other workloads that require flexible computing power.

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used for storing and retrieving large amounts of data. Organizations can use S3 to store documents, photographs, videos, application files, backups, archives, and other digital content.

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create a private, logically isolated network within AWS. A VPC provides control over network configurations such as IP addresses, subnets, routing, and security rules. It helps organizations create secure cloud environments and control how resources communicate with each other and external networks.

### AWS IAM

AWS Identity and Access Management (IAM) is a security service used to control access to AWS resources. Administrators can create users, groups, and roles and assign permissions based on specific responsibilities. IAM helps organizations follow the principle of least privilege by providing users and applications only the access they need.

## 5. Major Advantages of AWS

### Extensive Service Portfolio

AWS offers a broad collection of services that support computing, storage, databases, networking, security, analytics, artificial intelligence, and many other technical requirements.

### Worldwide Availability

AWS operates a global infrastructure that allows organizations to deploy applications in different geographic areas. This helps businesses improve application availability, reliability, and performance.

### Elasticity and Flexibility

Organizations can increase or decrease cloud resources as demand changes. This allows businesses to adapt to changing workloads without purchasing and maintaining large amounts of physical hardware.

## 6. Common Enterprise Applications

Businesses and other large organizations use AWS for a variety of IT and business operations, including:

* Hosting websites and web-based applications
* Storing, backing up, and archiving organizational data
* Running database-driven applications
* Processing and analyzing large datasets
* Developing and deploying Artificial Intelligence and Machine Learning solutions
* Moving traditional on-premises systems to the cloud
* Modernizing older applications and IT infrastructure
* Supporting business and enterprise applications
* Building globally distributed systems that can handle changing levels of demand
