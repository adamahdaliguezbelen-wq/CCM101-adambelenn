Laboratory 03 – Multi-Cloud Explorer
Mission Overview

Laboratory 03 focused on exploring and evaluating three of the leading cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Through this activity, I gained a better understanding of the services offered by each provider, their cloud infrastructure, key advantages, and the types of workloads they can support. The laboratory also demonstrated how cloud services can be matched to specific organizational and technical requirements.

Cloud Platforms Explored

The three cloud platforms investigated during the laboratory were:

Amazon Web Services (AWS)
Microsoft Azure
Google Cloud Platform (GCP)

Each platform provides comparable services for computing, storage, networking, security, databases, and application development. However, their features, integrations, and areas of specialization differ.

Possible Cloud Hosting Services

If the Linux server were transferred from the local or laboratory environment to the cloud, it could be hosted using virtual machine services offered by all three major providers.

Cloud Provider	Virtual Machine Service	Purpose
AWS	Amazon EC2	Provides scalable virtual servers for running Linux applications and workloads
Microsoft Azure	Azure Virtual Machines	Allows organizations to deploy and manage Linux-based virtual machines
Google Cloud	Compute Engine	Provides configurable virtual machines running on Google's cloud infrastructure

All three platforms can support Linux-based workloads through their respective virtual machine services. The most appropriate option would depend on several factors, including cost, computing requirements, performance, scalability, security, existing infrastructure, and organizational objectives.

Conclusion

Laboratory 03 provided practical experience in exploring, comparing, and evaluating multiple cloud platforms. Investigating AWS, Azure, and Google Cloud helped me recognize that although the providers offer many similar services, each has different strengths and capabilities. The Linux server investigation also showed how an existing workload can be evaluated before being migrated to a cloud environment.

Overall, this mission strengthened my understanding of multi-cloud computing and demonstrated how Linux administration concepts connect with cloud-based virtual machine services. It also emphasized the importance of considering technical and business requirements when selecting the most suitable cloud solution.
