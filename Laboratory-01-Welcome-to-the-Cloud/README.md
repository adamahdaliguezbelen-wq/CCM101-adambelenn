# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduced the basic skills required for working in a cloud-based Linux environment. The activities were completed using the KillerCoda Linux Playground and documented as part of my Cloud Computing Portfolio.

## Objectives

- Access a Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Create and organize files and directories.
- Document technical activities using Markdown.
- Maintain a version-controlled cloud computing portfolio using GitHub.

## Activities Performed

1. Accessed the KillerCoda Ubuntu Playground.
2. Created and logged in to a new Linux user account.
3. Checked the current username, working directory, and hostname.
4. Gathered Linux distribution, kernel, CPU, memory, and disk information.
5. Created and organized directories and Markdown files.
6. Created a GitHub repository for the Cloud Computing Portfolio.
7. Documented the laboratory activities using Markdown.
8. Used Git to commit and push the laboratory files to GitHub.

## Skills Learned

Through this laboratory, I learned how to work with a Linux command-line environment, manage users and directories, gather system information, create Markdown documentation, and organize technical work in a GitHub repository.

I also learned the importance of version control and maintaining organized technical documentation for cloud infrastructure work.
