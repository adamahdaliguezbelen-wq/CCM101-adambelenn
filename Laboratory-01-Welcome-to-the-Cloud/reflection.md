# Reflection

This laboratory helped me understand the importance of Linux in cloud computing. I learned how to access a cloud-based Linux environment, manage users, navigate directories, and gather system information using terminal commands.

I also learned how technical activities can be documented using Markdown and organized using GitHub. These skills are important because cloud engineers need to maintain clear documentation and version-controlled records of their work.

The activity gave me a foundation for the succeeding laboratories involving cloud infrastructure, virtualization, containers, and other cloud technologies.
